Dúvidas

Perguntas frequentes

Precisa instalar algum aplicativo?

Não. Funciona pelo navegador — Chrome, Safari, Firefox — sem download. Acesse pelo celular, tablet ou computador.

Como os responsáveis acessam o sistema?

A escola cadastra o responsável com o e-mail dele. No primeiro acesso, ele define a própria senha e acompanha os dados do filho direto pelo navegador.

Os dados de uma escola ficam separados de outra?

Sim. O isolamento é feito por regras de segurança no banco de dados. Nenhum usuário tem acesso — nem acidental — aos dados de outra escola.

Funciona bem no celular?

Sim. O sistema é responsivo. Professores fazem chamada pelo celular. Responsáveis acompanham tudo sem abrir computador.

Serve para escolas pequenas?

Sim. Não há número mínimo de alunos ou turmas. Funciona da mesma forma para 50 ou 2.000 alunos.

O responsável vê dados de outros alunos?

Não. Cada responsável vê apenas os dados do filho vinculado à sua conta. Garantido tecnicamente, não só por interface.

Pronto para começar?

Cadastre sua escola. Configure em menos de dez minutos.
