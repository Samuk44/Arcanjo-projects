Termos de Uso

Bem-vindo ao SGE v2.0. Ao utilizar nosso sistema de gestão escolar, você concorda com os seguintes termos:

1. Uso Autorizado: Este sistema é destinado exclusivamente para fins educacionais e administrativos da instituição.

2. Responsabilidade: O usuário é responsável por manter a confidencialidade de suas credenciais de acesso.

3. Conteúdo: Todos os dados inseridos devem ser precisos e atualizados.

4. Modificações: Reservamos o direito de modificar estes termos a qualquer momento.

Para mais informações, entre em contato com o suporte.

Política de Privacidade

A privacidade de seus dados é importante para nós.

Coleta de Dados: Coletamos informações pessoais apenas quando necessário para fornecer nossos serviços.

Uso de Dados: Seus dados são utilizados exclusivamente para fins educacionais e administrativos.

Proteção: Implementamos medidas de segurança para proteger suas informações.

Compartilhamento: Não compartilhamos seus dados com terceiros sem consentimento.

Sua privacidade é nossa prioridade.

Lei Geral de Proteção de Dados (LGPD)

Conforme a Lei Geral de Proteção de Dados (LGPD - Lei 13.709/2018):

Direitos do Titular: Você tem direito de acessar, corrigir, deletar e portar seus dados.

Consentimento: Seu consentimento é necessário para o tratamento de dados pessoais.

Segurança: Implementamos medidas técnicas e administrativas para proteger seus dados.

Transparência: Somos transparentes sobre como seus dados são utilizados.

Para exercer seus direitos, entre em contato conosco.
